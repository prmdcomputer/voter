# **App Name**: VoterFront

## Core Features:

- Dynamic Voter Data Entry: Structured form to input Epic numbers, local names, age, and constituency details with real-time field synchronization.
- Local Language Translation Tool: Uses AI as a tool to automatically translate name and address fields into Hindi, Punjabi, Gujarati, or other selected regional scripts.
- Live Dual-Sided Preview: Real-time visualization of the voter ID front and back card layouts, adjusting text and images dynamically.
- Photo Upload & Crop: A streamlined utility to upload voter portraits with automated resizing for the official ID template.
- QR Code Generator Tool: Automatically generates a scan-ready QR code embedding voter metadata for official validation.
- Print-Ready PDF Export: One-click generation of the final ID card into a high-resolution, print-ready PDF format.
- Voter Records Storage: A database system to save and retrieve previously generated voter card details and histories.

## Style Guidelines:

- Primary color: Professional Trust Blue (#335099), evoking authority and governmental reliability.
- Background color: Ultra-light Ice Gray (#F9FAFB), providing a clean, high-contrast workspace for document design.
- Accent color: Saturated Teal (#1791CF), used for call-to-action buttons and tool highlights to differentiate from official blue tones.
- Font Pairing: 'Poppins' for high-impact headlines and 'Inter' for crisp, readable form labels and card data. Both are grotesque sans-serifs that maintain clarity at small print sizes.
- Sharp, linear icons from the Boxicons library for field labels, such as identity card and location icons, using a solid blue fill.
- Responsive two-column dashboard: the left pane houses the input parameters, while the right pane remains fixed to show a high-fidelity live preview of the voter card.
- Subtle slide-and-fade transitions when switching regional languages to signal data re-calculation.
